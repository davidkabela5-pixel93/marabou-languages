# V0.6.5 — IA (préparation)
Architecture facultative, sans appel automatique ni interface de chat. Les leçons et données locales restent inchangées. Le module MarabouAI.request accepte endpoint HTTPS, jeton personnel fourni en mémoire, tâche tutor/correction, niveau A1/A2 et message explicite (1500 caractères maximum). Ne pas transmettre l'historique complet. Les réponses sont du texte non fiable, à afficher via textContent.
## Déploiement manuel (non effectué)
Créer un compte Cloudflare Workers et une clé Groq. Vérifier les quotas gratuits et la disponibilité du modèle. Depuis ai/ : npx wrangler login ; npx wrangler secret put GROQ_API_KEY ; npx wrangler secret put ACCESS_TOKEN (jeton aléatoire fort distinct de la clé Groq) ; npx wrangler deploy. Ne jamais committer les secrets ni les intégrer au JS public. Le jeton personnel devra être saisi explicitement lors de la future intégration UI.
CORS autorise l'origine GitHub Pages, pas un chemin particulier. Le jeton est indispensable. Limite de cinq requêtes/minute par emplacement Cloudflare, non globale ; les quotas Groq restent la limite finale. Pas de garantie de gratuité au-delà des quotas. Aucun stockage applicatif côté Worker ; les fournisseurs peuvent appliquer leurs propres politiques de rétention.
